# 全日本学生ハンドボール選手権大会 ワンストップ申込システム

## 開発（エンジニア向け）

```bash
npm install
npm run dev            # 開発用に起動（http://localhost:3000）
npm test               # ルール判定・写真検査の自動テスト
npm run build          # 本番用に書き出し（out/）
npm run preview:build  # 試作品を1つのHTMLにまとめる（preview/index.html）
```
