# M1 試作品 動作確認手順

- 対象：M1（チーム登録 → 選手名簿 → 写真アップロード）
- 作成日：2026年11月15日

---

## 試作品について

- スマホでもPCでも開けます。**入力した内容は、開いた端末のブラウザの中だけに保存されます**（ほかの人には見えません。サーバーには送られません）。
- 最初から「サンプル大学（東北地区）男子チーム」に、架空の選手4名・氏名のみの部員1名・役員1名が入っています。
- 画面上部の「最初の状態に戻す」で、いつでもサンプルの状態に戻せます。
- まだ入っていないもの：ログイン、ユニフォーム、集合写真・ロゴ、提出、保険・振込、交通宿泊（M2以降で追加します）。

## 確認していただきたいこと

### 1. トップ画面（やることリスト）
1. 開くと「男子チーム」のトップが表示されます。
2. 「やることリスト」に、まだ終わっていない作業が「!」で表示されていることを確認してください。
3. 「参加料の見込み」が 75,000円＋保険料（500円×人数）で計算されていることを確認してください。
4. 下の「チェック結果」に、直す必要がある項目が**選手の名前つきで**並んでいることを確認してください。

### 2. 基本情報・引率責任者
1. 「基本情報・登録番号・引率責任者」を開きます。
2. 連絡担当者・JHA登録番号・全日本学連登録番号を入れて「保存する」を押します。
3. トップに戻ると、やることリストのその行が「✓」に変わることを確認してください。
4. もう一度開き、「役員名簿との対応」を「役員名簿に登録していない」にして保存すると、トップに「**このままではベンチに入れません**」という注意が出ることを確認してください。

### 3. 選手名簿と自動チェック
1. 「選手名簿」を開き、「＋選手を追加する」を押します。
2. 氏名を入れ、**背番号に「7」**を入れると、その場で「背番号7が重複しています（仙台 健太・〇〇）」と表示されることを確認してください。
3. 背番号に「100」を入れて「保存する」を押すと、「背番号は1〜99」と表示されることを確認してください。
4. 「留学生の区分」を「短期留学生」にして「保存する」を押すと、エントリーできない旨が表示されることを確認してください。
5. 生年月日を **2010年1月1日**（大会時点で未成年）にすると、「ドーピング検査同意書」の確認欄が出ることを確認してください。
6. 入力が途中でも「途中のまま保存」で保存できることを確認してください（一覧に「要修正」と表示されます）。
7. 「氏名のみ掲載」に切り替えると、氏名とふりがな以外の欄が消えることを確認してください。

### 4. 顔写真のアップロード
1. 選手の編集画面で「本人が、顔写真を大会パンフレットに掲載することに同意しています」にチェックを入れます。
2. 「写真を選ぶ」から、次のような写真を試してください。

| 試す写真 | 期待する結果 |
|---|---|
| スマホのカメラで縦向きに撮った写真 | 「✓ 条件を満たしています」と表示され、縦3:横4に自動で切り抜かれる。スライダーで上下の位置を調整できる |
| 横向きに撮った写真 | 「横長の写真です。縦長の写真を選んでください」と表示されて使えない |
| LINEなどで送られてきた小さい画像・スクリーンショットの一部 | 「画像が小さすぎます（〇×〇px）」と表示されて使えない |
| PDFやiPhoneのHEIC形式の画像 | 「ファイルの形式が対応していません」と表示されて使えない |

3. 「この写真を使う」を押して保存すると、名簿の一覧に写真の小さな画像が出ることを確認してください。
4. ページを再読み込みしても、写真と入力内容が残っていることを確認してください。

### 5. 役員名簿・人数の上限
1. 「役員名簿」で役員を追加し、「学生です」にチェックすると保険が「加入」になることを確認してください。
2. 役員を6名登録したあとに7人目を追加しようとすると、追加できない旨が表示されることを確認してください。
3. 選手の「ベンチ登録する」を17名以上につけると、「ベンチ登録の選手は16名まで」と表示されることを確認してください。

### 6. 女子チーム
1. 上部の「女子チーム」を押し、「女子チームの申込を始める」を押すと、男子とは別の名簿で入力を始められることを確認してください。

## ご意見をいただきたい点

- 選手1人分の入力項目の順番・説明文はわかりやすいか
- エラーの文言（日本語）は、顧問・主務の方に伝わるか
- 写真の条件（縦3:横4・短辺600px以上）で、手持ちの写真が問題なく通るか
- ポジションの選択肢（GK・LW・LB・CB・RB・RW・PV）でよいか。「CP」のような大きな区分で足りるか
- 学年の選択肢（1〜6年）でよいか（大学院生の扱い）

## 技術メモ（エンジニア向け）

| 項目 | 内容 |
|---|---|
| ルール判定 | `src/lib/validation.ts`（画面に依存しない関数。`npm test` で自動テスト） |
| 写真の検査・切り抜き | `src/lib/image.ts` |
| 大会の設定の初期値 | `src/lib/settings.ts`（M2以降は管理画面からデータベースに保存） |
| データの保存 | `src/lib/store.ts`（M1はブラウザ内。M2でSupabaseに差し替え） |
| 本体の起動 | `npm install` → `npm run dev` |
| 試作品の1ファイル版 | `npm run preview:build` → `preview/index.html` |
