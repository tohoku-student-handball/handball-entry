# 全日本学生ハンドボール選手権大会 ワンストップ申込システム 要件定義書

- 版：第2版（承認済み）
- 作成日：2026年11月14日／更新：2026年11月15日（旅行社を3社程度・チームが1社を選ぶ方式に変更）
- 対象：令和9年度（2027年度）大会。主管：東北学生ハンドボール連盟
- 数値（金額・人数・日程）はR8年度要項の値を仮に使っています。R9年度要項が出たら**管理画面の設定で**差し替えます（プログラムの修正は不要）。

---

## 1. 目的

今は様式Ⅰ〜Ⅴ・旅行社への申込が紙・メール・Excelに分かれています。これを**1つのシステムで、1回入力すれば済む**ようにします。

- チームは名簿を1回入力するだけで、様式Ⅰ・Ⅱ・Ⅲ・Ⅳと旅行社向けのデータが自動でできあがる。
- 地区学連と事務局は、提出状況・入金・書類の到着・写真の不備を一覧で確認できる。
- 毎年の主管学連が交代しても、そのまま引き継いで使える。

## 2. ヒアリングで決まったこと

| 項目 | 決定内容 |
|---|---|
| 使い始める時期 | **2027年4〜5月に試験運用**（一部の地区・チームで）→ 6月の要項配布にあわせて本番受付 |
| ログイン方法 | **事務局がメールで招待**し、招待された人だけが登録できる |
| 費用の負担 | **今年度は東北学連が負担**。来年度以降に移す手順を引き継ぎ手順書にまとめる |
| 旅行社との連携 | **指定旅行社は3社程度**。**各チームが3社から1社を選び**、交通・宿泊・弁当をまとめてその1社に申し込む。旅行社ごとに**専用の閲覧画面**を用意する（旅行社がログインして確認・Excel出力・確定情報の入力をする） |
| パンフレット掲載項目 | 氏名・ふりがな・背番号・学年・ポジション＋**出身高校・身長・体重・学部・利き手** |
| 顔写真の条件 | **縦長（縦横比3:4）・短辺600px以上・JPEG/PNG・1枚10MBまで**（数値は管理画面で変更可） |
| ロゴの形式 | **PNG・JPEGのみ** |
| 個人情報の保管期間 | **全日本学連の規定に従う**（規定の内容を確認中。削除の時期は管理画面で設定できるようにする） |
| 承認の流れ | **チーム → 地区学連が承認 → 事務局**。地区学連は差し戻しもできる |
| 振込先 | **各地区学連の口座**。入金の確認は地区学連が行う |
| 紙の申込書（角印） | **全日本学連と相談して決める**。「紙を郵送」「押印済みPDFをアップロード」のどちらでも動くようにし、設定で切り替える |
| 自動メールの送信元 | **東北学連の既存Gmail** |

## 3. 使う人（ロール）と、できること

| ロール | 人数の目安 | できること |
|---|---|---|
| チーム担当者（顧問・主務など） | 1大学に1〜3名 | 自分の大学の男子・女子チームの申込入力、写真のアップロード、振込控えのアップロード、旅行社の確定内容の確認 |
| 地区学連担当者 | 1地区に1〜3名 | 自分の地区のチームだけを閲覧・承認・差し戻し、入金の確認、紙原本の到着の記録 |
| 事務局（全日本学連・主管学連） | 数名 | すべてのチームの閲覧、日程・金額などの設定、ロックの例外解除、各種出力（印刷会社・保険会社向け）、招待・リマインドの送信 |
| 旅行社 | 3社程度・各社数名 | **自社を選んだチームの分だけ**、交通・宿泊・弁当の申込内容の閲覧とExcel出力、確定情報（部屋割り・金額・変更）の入力。**他社を選んだチームは一切見えない**。名簿の個人情報も手配に必要な項目だけを見せる |

- **1つの大学に男子チームと女子チームがある**場合は、同じ大学アカウントの中で別々のチームとして管理します。
- 地区：北海道・東北・関東・北信越・東海・関西・中四国・九州（地区の一覧は設定で増減できる）。

## 4. 申込の流れ（状態）

```
未着手 → 入力中 → 提出済（地区学連の確認待ち） → 地区承認済 → 事務局確認済
                      ↑            │
                      └─ 差し戻し ─┘（地区学連または事務局がコメントをつけて戻す）
```

- **申込締切を過ぎると、名簿・背番号はロック**されて変更できません。事務局だけが、チームごとにロックを一時的に解除できます（解除した記録は必ず残る）。
- 提出・差し戻し・承認のたびに、関係者へ自動メールが届きます。

## 5. 機能要件

### A. 大会申込（様式Ⅰ・Ⅲ相当）

| 番号 | 内容 | 入力時の自動チェック |
|---|---|---|
| A-1 | 大学・チームの基本情報（大学名、男女、地区、連絡先） | 必須項目の入力漏れ |
| A-2 | 役員名簿（最大6名） | 6名を超えると登録できない |
| A-3 | 選手名簿（最大25名） | 25名を超えると登録できない |
| A-4 | ベンチ登録（役員5名・選手16名まで） | 上限を超えると登録できない ※ |
| A-5 | 背番号（1〜99） | 範囲外・**チーム内の重複**は登録できない |
| A-6 | 留学生の区分（なし／留学生／短期留学生） | 留学生のエントリーは**3名まで**、ゲームエントリーは**2名まで**、**短期留学生はエントリー不可** |
| A-7 | 引率責任者（様式Ⅲ） | 大学の専任教職員または部長が任命した者であることの確認チェック。役員名簿に登録されていない場合は「**ベンチ入りできません**」と注意を表示 |
| A-8 | JHA登録番号・全日本学連登録番号 | 番号の入力 ＋ 事務局が「確認済」にする欄 |
| A-9 | ユニフォーム（CP用・GK用） | それぞれ**濃い色・淡い色の2色以上**が必須。協賛企業名入りの有無（「有」のときは1着種ごとに10,000円・現地で現金払い、と表示） |
| A-10 | 未成年選手のドーピング検査 保護者同意書 | 生年月日から未成年を自動で判定し、「同意書を携帯している」の確認チェックを必須にする（同意書そのものはJHA Web登録システム側） |
| A-11 | 申込書PDFの出力 | 大学の角印欄つき。様式Ⅰ・Ⅲの体裁で出力 |
| A-12 | 紙原本の管理 | 「紙郵送」の設定時：未送付／郵送済／到着確認。「PDFアップロード」の設定時：押印済みPDFのアップロード→確認 |

※ ベンチ登録（試合ごとのゲームエントリー）を申込時点で決めるか、大会当日に決めるかは「8. 未確定事項」を参照。

### B. 傷害保険（様式Ⅳ相当）

- 選手・学生役員は**全員加入（自動で加入扱い）**。役員・トレーナー・引率責任者は**任意**（チェックで選ぶ）。
- 保険料は1名500円（設定で変更可）。加入人数から自動で計算する。
- 保険期間（大会前日から7日間）は設定値として管理する。
- 事務局が、保険会社に提出する名簿をExcel/CSVで一括出力できる。

### C. パンフレット原稿（様式Ⅱ相当）

- エントリー25名の掲載項目：**氏名・ふりがな・背番号・学年・ポジション・出身高校・身長・体重・学部・利き手**。
- 25名以外の部員は**氏名のみ**。
- アップロードする画像：選手・役員の顔写真、チーム集合写真、チームロゴ。
- **アップロード時の自動検査**（不適合のときは、理由を日本語で表示して受け付けない）：

| 種類 | 形式 | 大きさ | 縦横比 | 容量 |
|---|---|---|---|---|
| 顔写真 | JPEG/PNG | 短辺600px以上 | 3:4（縦長）※ずれが小さければ画面上で切り抜いて調整 | 10MBまで |
| 集合写真 | JPEG/PNG | 長辺2000px以上（仮） | 横長 | 20MBまで（仮） |
| ロゴ | PNG/JPEG | 短辺600px以上（仮） | 指定なし | 10MBまで |

  （数値はすべて管理画面で変更できる。（仮）は印刷会社に確認してから決める）
- 選手ごとに「**写真をパンフレットに掲載することに同意する**」チェックを設ける。同意がない選手は写真なしで掲載する。
- **入稿データの一括出力**（事務局）：Excel名簿 ＋ 画像フォルダをZIPにまとめる。
  - フォルダ：`男子/大学名/`、`女子/大学名/`
  - ファイル名：`チーム名_背番号_氏名.jpg`（役員は `チーム名_役員_役職_氏名.jpg`）
- **プレビュー**：パンフレットのチーム紹介ページに近い見た目で表示し、文字数オーバーや写真の不足がひと目でわかるようにする。

### D. 参加料・入金管理（様式Ⅴ相当）

- 参加料1チーム75,000円 ＋ 保険料500円×加入人数を自動計算（金額は設定で変更可）。
- 協賛ユニフォームの10,000円は**現地での現金払い**のため、振込額には含めず、別の一覧で管理する。
- 振込先は**チームが所属する地区学連の口座**を表示する（口座は地区ごとに設定）。
- 振込名義のルールを画面に表示する：**必ず大学名。男女とも参加する場合は末尾に「ダンシ」「ジョシ」**（例：トウホクダイガクダンシ）。
- チームが振込控え（画像/PDF）をアップロード → **地区学連**が照合してステータスを更新（未入金／確認中／入金確認済）。
- 入金額と請求額が違うときは、差額（過不足）を警告表示する。

### E. 交通・宿泊・弁当（旅行社連携）

- 指定旅行社（3社程度。社名・連絡先・受付締切は管理画面で登録）から、**チームが1社を選ぶ**。選んだ旅行社は手配の締切までは変更でき、締切後は事務局のみ変更できる。
- チームが1画面で希望を入力：宿泊（日程・人数・男女別の部屋数）、弁当（日付・個数）、交通（往復の手段・日時・人数）。
  - **具体的な入力項目は、旅行社にヒアリングしてから確定する**（「8. 未確定事項」）。
- 旅行社は専用画面にログインして、**自社を選んだチームの**申込内容を一覧で確認・Excel出力できる。
- 事務局は、どのチームがどの旅行社を選んだか・未選択のチームを一覧で確認できる。
- 旅行社は確定情報（部屋割り・金額・変更点）をシステムに入力し、チームは自分の画面で確認できる。確定・変更があるとチームにメールが届く。

### F. 取りまとめ・管理画面

- **地区学連の画面**：自分の地区のチームの状況（未着手／入力中／提出済／承認済）、入金、紙原本の到着、差し戻しコメント。
- **事務局のダッシュボード**：男女64枠の進み具合、未入金、書類未着、写真の不備、まとめてリマインド送信。
- **日程の設定**：申込締切、組み合わせ抽選日、振込締切、写真の締切、大会期間、保険期間などを管理画面で変更できる。
- **自動メール**：提出完了、差し戻し、承認、締切リマインド（7日前・前日。何日前に送るかも設定で変更可）。
- **変更履歴（監査ログ）**：誰が・いつ・何を・どう変えたかをすべて記録し、事務局が閲覧できる。

## 6. 非機能要件（使いやすさ・安全性など）

| 項目 | 要件 |
|---|---|
| 使う端末 | スマホ・PCの両方。名簿入力はスマホでもしやすい画面にする |
| 同時アクセス | 締切直前に64チーム＋地区学連（〜200人程度）が同時に使っても止まらない |
| 個人情報 | ・各ロールは自分に必要な範囲しか見られない（例：地区学連は自地区のみ、旅行社は手配に必要な項目のみ）<br>・通信はすべて暗号化（https）<br>・写真の利用目的（パンフレット掲載・大会運営）を画面に明示し、同意を取る<br>・大会終了後の削除・保管は全日本学連の規定に従い、削除日を設定して実行できる機能を設ける |
| 引き継ぎ | ・年度・大会ごとにデータを分け、前年度の設定（金額・日程・地区・口座など）を**複製して新年度を作れる**<br>・金額・日程・画像条件などは**すべて管理画面で変更**（プログラムを触らない）<br>・広く使われている仕組みだけを使い、特殊な技術に頼らない |
| 費用 | 年間で無料枠〜月数千円程度（詳しくは技術選定書） |
| メール | 東北学連の既存Gmailから送信（Gmailの1日の送信上限の範囲内で運用。64チーム規模なら問題ない） |
| バックアップ | データベースは毎日自動でバックアップ。写真は大会後の削除まで保管 |

## 7. やらないこと（今回の範囲外）

- 試合の組み合わせ抽選・試合結果の管理
- オンラインでの決済（クレジットカード等）。振込は従来どおり銀行振込
- JHA Web登録システムとの自動連携（登録番号の入力と目視確認のみ）
- パンフレット自体のレイアウトデザイン（印刷会社が行う。システムは入稿データとプレビューまで）
