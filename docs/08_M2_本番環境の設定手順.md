# M2 本番環境の設定手順（Supabase・Gmail・Vercel）

- 作成日：2026年11月21日
- 対象：大会事務局の担当者（非エンジニア向け）
- 所要時間：40分ほど
- 前提：docs/07 の「Supabase のプロジェクト作成」「Gmail のアプリパスワード作成」が終わっていること

> **大事なこと**：この手順で扱うパスワード（データベースのパスワード、Gmailのアプリパスワード）は、Supabase の画面に直接入力します。チャットやメールには貼らないでください。

---

## 1. データベースを準備する（SQLを2回貼り付ける）

> **2026年11月の作り直し（M2.5）以降は、設定文が2つのファイルにまとまりました。**
> - `supabase/schema.sql`：表・権限・関数のすべて（**既存の表を消してから作り直します**。データが入ったあとの本番では実行しないでください）
> - `supabase/seed.sql`：令和9年度の大会（全日本学生選手権・春季東北学生リーグ）と、最初の事務局担当者
>
> **注意**：設定文のページをブラウザの自動翻訳で日本語にした状態でコピーすると、文が壊れて実行できません。翻訳は「原文を表示」にしてからコピーしてください。

### 1-1. 表・権限・関数の設定
1. 次のURLを開き、全文をコピーします（Ctrl+A → Ctrl+C）。
   - https://raw.githubusercontent.com/tohoku-student-handball/handball-entry/main/supabase/schema.sql
2. Supabase の「**SQL Editor**」→「**New query**」に貼り付けて「**Run**」。
3. 「**Success. No rows returned**」と出れば完了です。

### 1-2. 大会と最初の事務局担当者の登録
1. 次のURLの全文をコピーして、新しいクエリに貼り付けます。
   - https://raw.githubusercontent.com/tohoku-student-handball/handball-entry/main/supabase/seed.sql
2. **いちばん下の `'ここにメールアドレス'` と `'ここに氏名'` を書き換えます**（前後の `'` は残す）。この人が両方の大会の事務局（主催者）になります。
3. 「**Run**」を押し、結果に `bootstrap_office` の行が2つ出れば完了です。
4. 確認：「Table Editor」の `tournaments` に2つの大会、`divisions` に3つの部（男子1部・男子2部・女子）が入っていれば成功です。

## 2. メールの送信設定（Gmailから送る）

Supabase の標準のメール送信は1時間に数通しか送れないため、東北学連の Gmail から送るように設定します。

1. Supabase の左のメニュー「**Authentication**」→「**Emails**」→ 上のタブ「**SMTP Settings**」を開きます。
2. 「**Enable custom SMTP**」をオンにして、次のように入力します。

| 欄 | 入力するもの |
|---|---|
| Sender email | 東北学連の Gmail アドレス |
| Sender name | `全日本学生ハンドボール選手権 申込システム` |
| Host | `smtp.gmail.com` |
| Port number | `465` |
| Username | 東北学連の Gmail アドレス |
| Password | docs/07 で作った **アプリパスワード（16文字）** |

3. 「**Save changes**」を押します。
4. 「**Authentication**」→「**Rate Limits**」で、「Rate limit for sending emails」を `100`（1時間あたり）程度にして保存します。

## 3. ログインメールの文面を日本語にする

1. 「**Authentication**」→「**Emails**」→ 上のタブ「**Templates**」を開きます。
2. 「**Magic Link**」と「**Confirm signup**」の**両方**を、次の内容に書き換えて「Save」を押します。
   （初めてログインする人には「Confirm signup」、2回目以降の人には「Magic Link」のメールが届きます）

**Subject（件名）**
```
【全日本学生ハンドボール選手権】申込システムへのログイン
```

**Message body（本文）**：右側の「Source」に次をそのまま貼り付けます。
```html
<p>全日本学生ハンドボール選手権大会 申込システムへのログインのご案内です。</p>
<p>次のボタンを押すとログインできます（1時間以内に開いてください）。</p>
<p><a href="{{ .ConfirmationURL }}" style="display:inline-block;padding:10px 20px;background:#1f5fae;color:#fff;text-decoration:none;border-radius:6px;">ログインする</a></p>
<p>ボタンが開けない場合は、ログイン画面で次の確認コードを入力してください。</p>
<p style="font-size:24px;font-weight:bold;letter-spacing:4px;">{{ .Token }}</p>
<p>このメールに心当たりがない場合は、破棄してください。<br>東北学生ハンドボール連盟（大会事務局）</p>
```

## 4. 画面を公開する（Vercel）

1. **vercel.com** にログインし、「**Add New…**」→「**Project**」を押します。
2. 「Import Git Repository」に `tohoku-student-handball/handball-entry` が出ていれば「**Import**」を押します。
   - 出てこない場合は「**Adjust GitHub App Permissions**」を押し、**連盟アカウント（tohoku-student-handball）でログインして**、Vercel のアプリに `handball-entry` へのアクセスを許可してください。
3. 設定画面は何も変えずに「**Deploy**」を押します（Framework Preset は自動で「Next.js」になります）。
4. 1〜2分で完了し、`https://handball-entry-〇〇〇.vercel.app` のような**公開URL**が表示されます。これを控えてください。

## 5. 公開URLを Supabase に登録する

ログインメールのリンクが正しい画面に戻るように設定します。

1. Supabase の「**Authentication**」→「**URL Configuration**」を開きます。
2. 「**Site URL**」に、4で控えた公開URLを入力して保存します。
3. 「**Redirect URLs**」の「Add URL」で、同じ公開URLを追加します。

## 6. 動作確認

1. スマホまたはPCで公開URLを開くと、「申込システムにログイン」の画面が出ます。
2. 1-2で登録したメールアドレスを入れて「ログイン用のメールを送る」を押します。
3. 届いたメールの「ログインする」を押す（または確認コードを入力する）と、「**全体の申込状況**」（事務局の画面）が開けば成功です。
4. 続けて「docs/09_M2_動作確認手順.md」の確認に進んでください。

**終わったら、公開URLを私に教えてください。** うまくいかないところがあれば、画面に出ている文章をそのまま教えてください（パスワード類は除いて）。
