# M2.5 本番データベースの作り直しと確認手順

- 対象：M2.5（年度の部員名簿・大会ごとのエントリー・全日本とリーグの切り替え・部・1段階承認・大会の設定）
- 作成日：2026年11月24日

---

## 1. M2.5 で変わったこと

| 変わったこと | 内容 |
|---|---|
| **部員名簿（年度）** | 大学×男女×年度で、部員の情報（氏名・ふりがな・生年月日・学年・ポジション・写真など）を**1回だけ**入力します。春季リーグ・秋季リーグ・全日本で共通です |
| **エントリー（大会ごと）** | 各大会では、部員名簿から人を選び、**その大会の背番号・ベンチ登録・役職**だけを決めます。背番号は大会ごとに変えられます |
| **大会の切り替え** | 画面のいちばん上の大会名を押すと、関わっている大会（全日本・春季リーグなど）を切り替えられます |
| **全日本とリーグ** | リーグでは、パンフレット（写真）・引率責任者・申込書の郵送・保険を使わない設定になっており、入力も必須ではありません |
| **部** | リーグでは、大学ごとに男子1部・男子2部・女子などの部を登録します。チームは自動でその部に入ります |
| **1段階の承認** | リーグは「チームが提出 → 東北学連（主催者）が承認」の1段階です。全日本は従来どおり「地区学連 → 事務局」の2段階です |
| **大会の設定** | 主催者が、締切日時・人数の上限・金額・使う機能を画面から変更できます（事務局の画面 →「大会の設定」） |

## 2. 本番データベースの作り直し（10分）

いまの本番データベース（M2で作ったもの）を、新しい形に作り直します。**テスト用に入れたデータ（大学・担当者・名簿）は消えます。** メールの設定・ログインメールの文面・Vercel・URLの設定はそのまま使えます。

1. **docs/08 の「1-1」**：`supabase/schema.sql` を SQL Editor で実行します（既存の表を消してから作り直します）。
2. **docs/08 の「1-2」**：`supabase/seed.sql` の最後の2行を書き換えて実行します。
3. 公開URL（handball-entry.vercel.app）を開き直してログインします（ログインし直す必要はないことが多いです）。
4. 画面のいちばん上に**大会名の切り替え**が出て、「全日本学生選手権」と「春季東北学生リーグ」を選べれば成功です。

> 作り直しのあと、Vercel の画面は自動で新しい版に更新されています（GitHub に保存した時点で自動公開）。

## 3. デモ版で確認すること

デモ版（共有したリンク）では、最初から2つの大会のサンプルが入っています。

### 3-1. 部員名簿は1回だけ
1. 「チーム担当者」→「部員名簿（年度・全大会で共通）」を開き、選手を1人追加します。
2. 「エントリー（この大会の背番号・ベンチ）」を開き、追加した選手を「エントリー」にして背番号を入れます。**同じ背番号を入れると赤くなる**ことを確認してください。
3. 画面上の大会名を「春季東北学生ハンドボールリーグ」に切り替えます。
4. 「男子チームの申込を始める」を押します（所属の部「男子1部」が表示されます）。
5. リーグの「エントリー」を開くと、**さきほど追加した選手も含めて同じ名簿が並んでいる**ことを確認し、全日本とは**別の背番号**を付けて保存します。

### 3-2. リーグでは入力が少なくて済む
1. リーグの「基本情報」に**引率責任者の欄がない**ことを確認します。
2. リーグのやることリストに、顔写真・集合写真・ロゴ・申込書の郵送が**出てこない**ことを確認します。
3. ユニフォームを入れて「最終確認・提出」から提出します。

### 3-3. リーグの承認は1段階
1. 上の「事務局（主催者）」に切り替えます（リーグでは「地区学連」は出てきません）。
2. 一覧に部ごとの件数（男子1部・男子2部・女子）が出ることを確認します。
3. 提出されたチームを開き、「**承認する（受付完了）**」を押すと、そのまま「確認済（受付完了）」になることを確認します。

### 3-4. 大会の設定と部の割り当て
1. 「大会の設定」で、締切日時や参加料を変えて保存します。チームの画面の締切表示・参加料が変わることを確認します。
2. 「大学・担当者の登録」で、登録済みの大学の部（男子1部 → 男子2部など）を変えられることを確認します。

## 4. 本番で確認すること（作り直しのあと）

1. 事務局として、**春季リーグ**を選び、「大学・担当者の登録」で次を登録します。
   - 大学：「テスト大学」（男子の部：男子1部）
   - 担当者：メールアドレスA／チーム担当者／テスト大学
2. Aでログインし、部員名簿に2〜3人入れて、リーグにエントリー・提出します。
3. 事務局で承認します。
4. 次に、**全日本**を選んで、同じテスト大学（東北地区）と担当者Aを登録します。
5. Aで大会を全日本に切り替え、**部員名簿がそのまま使える**こと、背番号を別に付けられることを確認します。
