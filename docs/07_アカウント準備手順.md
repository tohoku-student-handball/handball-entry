# アカウント準備手順（GitHub・Supabase・Vercel・Gmail）

- 作成日：2026年11月20日
- 対象：東北学生ハンドボール連盟の担当者（非エンジニア向け）
- 所要時間：全部で1時間ほど（一度にやらなくても大丈夫です）

---

## 0. 全体像と基本ルール

| サービス | 何に使うか | 名義 |
|---|---|---|
| GitHub | システムのプログラムの保管場所 | 連盟の「組織」を作り、担当者が個人アカウントで参加 |
| Supabase | データベース・ログイン・写真の保管 | 連盟の「組織」を作り、担当者が参加 |
| Vercel | 画面の公開（チームが開くURL） | GitHubの組織とつなぐ |
| Gmail | 自動メールの送信元 | 東北学連の既存Gmail |

**基本ルール**
1. **連絡先メールは、すべて東北学連のGmailにする。** 個人のメールにすると、担当交代のときに通知が届かなくなります。
2. **管理者は必ず2人以上にする。** 1人だと、その人と連絡が取れなくなったときに誰も管理できなくなります。
3. **パスワード・合言葉（キー）はチャットやメールに貼らない。** 私（Claude）にも貼らないでください。必要なときは、専用の入力画面をこちらから表示します。
4. 作ったアカウントの一覧（サービス名・ログインに使うメール・管理者）は、この手順書の最後の「記録表」に書き残してください（パスワードは書かないでください）。

## 1. GitHub：連盟の組織を作る

GitHubでは、組織は「個人アカウントの持ち主」が作ります。今お使いの個人アカウント（kh-kuwahara-stack）で作業します。

1. PCのブラウザで **github.com** を開き、いつものアカウントでログインします。
2. 画面右上の**自分のアイコン**をクリック →「**Your organizations**」→ 緑の「**New organization**」を押します。
3. プランの選択で「**Free**」の「**Create a free organization**」を押します。
4. 次のように入力します。
   | 欄 | 入力するもの |
   |---|---|
   | Organization name（組織名） | 英数字とハイフンのみ。例：`tohoku-handball` または `tohoku-student-handball`（URLになり、あとから変えると面倒なので慎重に） |
   | Contact email | **東北学連のGmail** |
   | This organization belongs to | 「**My personal account**」ではなく「**A business or institution**」を選び、名称に「東北学生ハンドボール連盟」と入力 |
5. 利用規約に同意して「**Next**」。メンバー招待の画面は、いったん「**Skip this step**」で構いません。
6. **2人目の管理者を招待します。** 組織のページ →「**People**」→「**Invite member**」→ 2人目の方のGitHubアカウント名またはメールを入力 → 役割（Role）を「**Owner**」にして招待します。
   - 2人目の方はGitHubの個人アカウントを持っている必要があります（無料・github.com の「Sign up」から作れます）。

## 2. GitHub：今のリポジトリを組織に移す

今のプログラムは個人アカウント（kh-kuwahara-stack）の下の `incol` にあります。これを組織に移します。これまでの履歴はそのまま移ります。

1. **github.com/kh-kuwahara-stack/incol** を開きます。
2. 上のタブの「**Settings**」（歯車）を押します。
3. 「General」のページをいちばん下までスクロールし、赤い枠の「**Danger Zone**」にある「**Transfer ownership**」の「**Transfer**」を押します。
4. 「New owner」で、1で作った**組織**を選びます。
5. 確認のため、表示どおりに `kh-kuwahara-stack/incol` と入力し、「**I understand, transfer this repository**」を押します。
6. （任意）名前をわかりやすくする：移した先のリポジトリで「Settings」→「General」→「Repository name」を `handball-entry` などに変えて「Rename」。
7. **リポジトリを公開設定にします。** 「Settings」→「General」→ いちばん下の「Danger Zone」→「**Change repository visibility**」→「**Change to public**」。
   - プログラムだけが公開され、**名簿・写真・パスワードは一切含まれません**（それらはSupabase側に保存します）。
   - 公開にしておくと、Vercelの無料プランで確実に公開でき、ほかの地区の学連も参考にできます。
   - どうしても非公開にしたい場合は、私にお知らせください。非公開でも無料で使える別の公開サービスに切り替えます。

**終わったら、新しいリポジトリのURL（例：github.com/tohoku-handball/handball-entry）を私に教えてください。** 作業先を切り替えます。

## 3. Supabase：組織とプロジェクトを作る

1. PCのブラウザで **supabase.com** を開き、右上の「**Start your project**」または「**Sign in**」を押します。
2. 「**Continue with GitHub**」を押し、1で使ったGitHubアカウントでログインします（パスワードを増やさずに済みます）。
3. 組織（Organization）を作る画面が出たら、次のように入力します。
   | 欄 | 入力するもの |
   |---|---|
   | Name | `東北学生ハンドボール連盟` |
   | Type | 「Non-profit」などがあれば、それを選ぶ |
   | Plan | **Free**（受付期間の5月から有料プランに切り替えます。今はお金はかかりません） |
4. 続けてプロジェクトを作ります。
   | 欄 | 入力するもの |
   |---|---|
   | Project name | `handball-entry-r9`（令和9年度用） |
   | Database Password | 「**Generate a password**」で自動作成 → **連盟のパスワード管理の方法（金庫・パスワード管理アプリ等）に保管**。チャットやメールには貼らないでください |
   | Region | **Northeast Asia (Tokyo)** |
5. 「**Create new project**」を押します。準備に数分かかります。
6. **2人目の管理者を招待します。** 左下の歯車「Organization settings」（または組織名）→「**Team**」→「**Invite**」→ メールアドレスを入力し、役割を「**Owner**」または「**Administrator**」にします。
7. 請求先メール（Billing email）がある場合は、**東北学連のGmail**にしておきます。

**終わったら、プロジェクトのURL（`https://〇〇〇.supabase.co` の形。プロジェクトの「Project Settings」→「API」または「Data API」に表示）を教えてください。** このURLは公開して問題ない情報です。それ以外の「service_role」「secret」と書かれたキーは、私にも貼らないでください。

## 4. Vercel：アカウントを作る

1. PCのブラウザで **vercel.com** を開き、「**Sign Up**」を押します。
2. 種類を聞かれたら「**Hobby**」（無料）を選び、名前に「東北学生ハンドボール連盟」と入力します。
3. 「**Continue with GitHub**」を押し、1のGitHubアカウントでつなぎます。
4. GitHubの組織へのアクセスを聞かれたら、1で作った**組織**を選び、「**Only select repositories**」で2で移したリポジトリだけを許可します。
5. ここまでで止めて大丈夫です。プログラムの公開（Import）は、M2の準備ができたら私と一緒に行います。

**注意**：Vercelの無料プランには「営利目的で使わないこと」という条件があります。学生連盟の大会申込は営利目的ではないと考えていますが、全日本学連として気になる場合はお知らせください（有料プランは月約3,000円、または同等の無料サービスに切り替え可能です）。規約は登録時の画面で最新の内容をご確認ください。

## 5. Gmail：自動メール用の「アプリパスワード」を作る

自動メール（提出完了・差し戻し・締切リマインド）を、東北学連のGmailから送るための専用パスワードです。普段のGmailのパスワードとは別のものです。

1. 東北学連のGmailでログインした状態で、**myaccount.google.com** を開きます。
2. 左の「**セキュリティ**」→「**2段階認証プロセス**」が「オフ」なら、画面の案内に従って**オン**にします（担当者のスマホで確認コードを受け取る設定。担当交代時は電話番号の付け替えが必要なので、記録表に誰のスマホかを書いておいてください）。
3. 画面上部の検索欄で「**アプリパスワード**」と検索して開きます。
4. アプリ名に `handball-entry` と入力して「**作成**」を押すと、16文字のパスワードが表示されます。
5. **このパスワードは一度しか表示されません。** パスワード管理の方法に保管してください。チャットやメールには貼らないでください。M2で、Supabaseの設定画面に直接入力していただきます（入力場所は私がご案内します）。

## 担当交代のとき（引き継ぎの要点）

1. 新しい担当者に、GitHub・Supabaseの組織へ「Owner」として招待を送る。
2. 新しい担当者が参加できたことを確認してから、前の担当者を組織から外す。
3. Gmailの2段階認証のスマホを新しい担当者に付け替え、アプリパスワードを作り直してSupabaseに入力し直す。
4. この記録表を更新する。
